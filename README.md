# 魔方 · 打乱与复原

离线运行的三阶魔方演示。随机生成 25 步打乱公式，查看每一步的面与方向，再用 Kociemba 两阶段算法计算并播放复原步骤。

## 直接使用

用现代浏览器打开根目录的 `index.html`。应用不需要登录、联网、安装依赖或启动服务器；样式、Three.js 和后台求解器已经内嵌。

1. 点击 **随机打乱**，生成公式。
2. 点击 **下一步** 或 **自动打乱**，执行打乱。
3. 打乱完成后点击 **计算复原步骤**。
4. 点击 **下一步** 或 **自动复原**；播放过程中可以暂停。
5. **从头跟做这组打乱** 可重放同一公式。拖动魔方区域可以旋转视角。

跟做实体魔方时，先复原，白色中心朝上、绿色中心朝前、红色中心朝右。U / D 是上下，L / R 是左右，F / B 是前后。顺逆时针以正对要转的面为准；`′` 表示逆时针，`2` 表示 180°。

需要支持 WebGL 2、Web Workers 和现代 JavaScript 的浏览器。手机的系统文件预览器可能无法执行 HTML；可使用支持本地 HTML 的浏览器或静态托管。求解器第一次初始化需要数秒，较慢设备可能更久。

打乱是随机转动序列，不宣称符合赛事的随机状态打乱规范。求解结果较短，180° 计为一步，不保证全局最优。

## 修改与构建

需要 Node.js 22 或更新版本。依赖只用于开发和构建，使用生成的 HTML 不需要 npm。

```sh
npm ci --ignore-scripts
npm run build
npm run check
npm audit
```

构建会更新根目录 `index.html` 并重新计算内容安全策略中的脚本 SHA-256。修改 `src/` 后必须重新构建；直接修改生成的脚本会使其哈希失效。`npm run build:check` 确认发布文件与源码一致。

若本地 HTML 无法运行，可在项目目录启动仅监听本机的预览服务器：

```sh
python -m http.server 8080 --bind 127.0.0.1
```

然后打开 `http://127.0.0.1:8080`。这是本机预览，不会发布网站。
